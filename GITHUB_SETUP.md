# 🚀 GitHub Repository Setup Guide

## Step 1: Create Repository on GitHub
1. Go to https://github.com
2. Click "New repository" (green button)
3. Repository name: `advanced-soil-monitoring-iit-bombay`
4. Description: `🌱 Advanced IoT Soil Monitoring System - IIT Bombay AWS X Impact Challenge 2025 Winner`
5. Make it **Public** (to showcase your work)
6. **DON'T** initialize with README (we already have one)
7. Click "Create repository"

## Step 2: Connect Local Repository to GitHub
After creating the repo, GitHub will show you commands. Use these:

```bash
# Add remote origin (replace YOUR_USERNAME with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/advanced-soil-monitoring-iit-bombay.git

# Push to GitHub
git branch -M main
git push -u origin main
```

## Step 3: Verify Upload
1. Refresh your GitHub repository page
2. You should see all files uploaded
3. README.md will display automatically
